# Assets para Voa Porco

| Fonte | Melhor uso | Licença |
|---|---|---|
| [Kenney](https://kenney.nl/assets) | Props, veículos, construções e interface com estilo consistente | Assets CC0; confira a página do pacote |
| [Quaternius](https://quaternius.com/) | Personagens e cenários low-poly para adaptar à direção voxel | Confira a licença do pack; o catálogo inclui modelos CC0 |
| [itch.io — voxel gratuito](https://itch.io/game-assets/free/tag-voxel) | Pacotes voxel e pixel 3D independentes | Gratuito não implica livre redistribuição; licença varia |

| [Sketchfab](https://sketchfab.com/) | Modelos de referência e itens específicos com download habilitado | Verifique licença, autoria e atribuição em cada modelo |

Começar com um único pack Kenney para elementos de rua ajuda a manter escala, cores e desempenho. Para Cipó: banca, postes, bancos, barracas e vegetação. Para novas skins: uma base articulada única, acessórios em voxel e texturas pequenas com filtro nearest.

Antes de integrar: registrar autor/URL/licença em um manifesto, conferir orçamento de polígonos e texturas, converter para GLB quando aplicável e testar em celular. As skins atuais são construídas em código; nenhum modelo externo desses catálogos foi incluído nesta entrega.

Referências de licença: [Kenney](https://kenney.nl/support), [Quaternius](https://quaternius.com/faq.html), [OpenGameArt](https://opengameart.org/content/faq).
